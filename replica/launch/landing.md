# Landing page (built in `web/src/app/page.tsx`)

Angle: **verified, free, no install.** Brand voice: plain, exact, calm. No testimonials, user counts, logos or reviewer quotes. The proof is the public source status page, which is real data.

1. **Hero.** Headline: "Find every account. See why each one counts." Sub-line: free, no install, 320 sources checked daily. One action: the search box itself. Visual: a product panel showing a finished search.
2. **The problem** (paraphrased from the top two themes, no quotes):
   - Username tools often say "found" when there's nothing there.
   - Their checks quietly break as sites change, and a blocked check looks the same as "no account".
3. **How it works.** Three steps:
   1. Enter what you have.
   2. Every source answers live.
   3. Verify and keep what holds up.
4. **What's different.** Leads with the fixes:
   - "Why this counts" on every result (fix #1).
   - Daily fixture checks plus the public status page (fix #3).
   - Report a wrong result (fix #2).
   - Didn't answer is never "no account".

   Then parity: domain and email search, cases, export, tools, free API.
5. **Coverage.** Counts per category, with every source listable (real data from the engine).
6. **Price.** "Free. No plans, no credits, no trial." Plus a one-line note on abuse limits.
7. **FAQ.** Omitted: the user asked for no FAQ.
8. **Final call to action.** "Investigate responsibly" and "Create a free account".

Contrast: page tokens checked, 0 AA failures. axe runs on `/` in e2e (desktop and mobile).
